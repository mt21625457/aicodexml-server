# Milestone v1.0: AI Code XML Web Multilingual

**Status:** SHIPPED 2026-03-16
**Phases:** 1-5
**Total Plans:** 14

## Overview

This milestone retrofitted full English and Simplified Chinese support into the existing `aicodexml-web` Angular application without breaking the server repository's packaging flow. It established a single runtime i18n architecture, added locale persistence and locale-aware formatting, localized shared shell/auth/common UI, completed a route-level feature sweep, and closed with verification plus guardrails against future hard-coded UI regressions.

## Milestone Summary

**Key Decisions:**

- Use runtime JSON catalogs with `ngx-translate` and a centralized `LocaleService` instead of per-locale builds.
- Persist locale under `views.language` through the existing user-preference document rather than creating a new locale-specific backend flow.
- Standardize locale-sensitive rendering through shared `smDate`, `smNumber`, and `smPercent` helpers plus locale-aware service formatting.
- Enforce future multilingual hygiene with a baseline-backed local guardrail so new regressions fail fast without blocking on full historical cleanup.

**Issues Resolved:**

- Server packaging now builds the local `aicodexml-web` submodule and ships translation assets in the existing Docker flow.
- The startup `NG0200` circular dependency that blocked browser verification was removed by making locale resolution bootstrap-safe.
- Known mixed-language literals identified during the final verification sweep were migrated to translation keys and catalog entries.

**Issues Deferred:**

- Authenticated post-login route traversal was not exercised end-to-end because no local QA session or dedicated credentials were available.
- Nyquist validation coverage remains partial because phases 1-3 do not yet have retrospective `VALIDATION.md` files.

**Technical Debt Incurred:**

- The checked-in i18n guardrail baseline is intentionally large and still preserves historical hard-coded-string findings.
- Pre-existing frontend lint debt and stylesheet-budget warnings remain outside the bilingual milestone scope.
